# Writing skills

把生硬、翻译腔的英文改成读得下去的英文。

| Skill | 目录 | 做什么 |
|-------|------|--------|
| English writing | [`english-writing/`](english-writing/) | 一段特别土的英文，改成流畅的英文 |

安装方式与 [visualization/README.md](../visualization/README.md) 相同：将 skill 目录（文件夹名 = `SKILL.md` 里的 `name`）拷到 `~/.cursor/skills/` 或项目 `.cursor/skills/`。

```text
用 english-writing，把下面这段改成流畅的英文。
```
