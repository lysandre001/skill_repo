# Writing skills

英文润色。改句子，不改原意、覆盖范围、例子和数字。

| Skill | 目录 | 做什么 |
|-------|------|--------|
| 英文润色 | [`english-proofing/`](english-proofing/) | 把英文改通、改一致；技术词和类别边界保持原样 |

安装方式与 [visualization/README.md](../visualization/README.md) 相同：将 skill 目录（文件夹名 = `SKILL.md` 里的 `name`）拷到 `~/.cursor/skills/` 或项目 `.cursor/skills/`。

```text
用 english-proofing，润色下面这段英文。
```
